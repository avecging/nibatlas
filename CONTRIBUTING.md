# Contributing to Nib Atlas

Thank you for helping make Nib Atlas useful to the fountain-pen community.

By submitting a contribution, you confirm that you have the right to provide it
and agree that accepted software and documentation contributions are licensed
under `AGPL-3.0-only`.

## Keep contributions publishable

Never commit or place in an issue, pull request, workflow log, or artifact:

- passwords, API keys, tokens, database connection strings, or private keys;
- personal contact details or other personal information without explicit
  publication consent;
- private illustrator or supplier agreements, rates, invoices, negotiations, or
  correspondence;
- outreach lists, private replies, permission records, or unpublished research;
- artwork, photographs, logos, or catalogue material without documented rights.

Use placeholders in examples. Put operational secrets only in the approved
GitHub or hosting-provider secret stores.

Shop facts should cite public sources and follow the repository's data-honesty
rules. Nib Atlas branding, catalogue data, and commissioned artwork are excluded
from the software licence; see [NOTICE.md](NOTICE.md).

Report security-sensitive material privately as described in
[SECURITY.md](SECURITY.md), not in a public issue.
