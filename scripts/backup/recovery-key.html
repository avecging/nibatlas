Create your backup recovery key

Your browser creates the key on this device. This file has no network access and never sends either key anywhere.

1. Save the private recovery key

Copy it into your password manager as the password for a record named Nib Atlas Backup Recovery. Keep an offline spare later. Do not send the private key in chat or store it with your backups.

2. Share only this public key

The public key locks backups but cannot unlock them. It starts with age1. This is the only key to send to the backup setup.

Keep this page open until the private key is safely saved. Reopening it does not recover previously generated keys. Chrome 133 or newer supports the required browser cryptography.
